# Package manifest

## Included

- Frozen RQ1 experimental and test-evaluation protocols.
- Core model, loss, training, evaluation, diagnostics, and verification code.
- Frozen inner/outer split definition.
- Dependency pins, citation metadata, and data-layout documentation.
- Completed-experiment narrative reports for audit context.

## Intentionally excluded

- Processed or raw telemetry CSV files.
- Trained model weights (`*.npz`, `*.pt`, `*.pth`, `*.ckpt`).
- Per-run predictions, histories, and generated output trees.
- Local environments, caches, credentials, and machine-specific paths.

The source archive used to prepare this package was left unchanged. No excluded file was deleted from the source archive or Google Drive.
